# 🎸 Club de Musique — ESTL (Registration Portal)

Plateforme web d'inscription en ligne pour le **Club de Musique** de l'**École Supérieure de Technologie de Laâyoune (ESTL)**.

---

## 🚀 Démo en direct
👉 [Visiter le site web](https://club-musique-estl.vercel.app)

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Icons:** Lucide React
- **Backend & Database:** Supabase (PostgreSQL)
- **Deployment:** Vercel

---

## ✨ Fonctionnalités

- 📝 Formulaire d'inscription dynamique pour les étudiants.
- 🗄️ Stockage instantané des données sur Supabase (`Full_Name`, `Filiere`, `Niveau`, `musical_instrument`, `Telephone`).
- 🎨 Design sombre moderne, responsive et adapté aux mobiles.
- 🇲🇦 Contenu adapté au contexte universitaire de l'ESTL.

---
